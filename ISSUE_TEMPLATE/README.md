# Issue Templates

このディレクトリには、GitHubのIssue作成時に使用するテンプレートが含まれています。

## テンプレート一覧

### 🐞 バグ報告 / Bug Report
- **ファイル**: `BUG_REPORT.md`
- **用途**: 既存のシステムに不具合がある場合・更新しなければならないタスクなど
- **ラベル**: `bug`

### 📊 データリクエスト / Data Request
- **ファイル**: `DATA_REQUEST.md`
- **用途**: データ抽出・分析・レポート作成などの依頼
- **ラベル**: `data-request`

### ✨ 機能要望 / Feature Request
- **ファイル**: `FEATURE_REQUEST.md`
- **用途**: 新機能の追加・既存機能の拡張についての提案
- **ラベル**: `enhancement`

### 🛠 改善提案 / Improvement
- **ファイル**: `IMPROVEMENT.md`
- **用途**: 既存プロセスやシステムの改善・効率化の提案
- **ラベル**: `improvement`

### 🔍 調査依頼 / Investigation Request
- **ファイル**: `INVESTIGATION.md`
- **用途**: 不明点の調査・原因究明・技術検証などの依頼
- **ラベル**: `investigation`

### 📘 仕様確認 / Specification Clarification
- **ファイル**: `SPEC_CLARIFICATION.md`
- **用途**: 仕様の確認・明確化・ドキュメント整備などの依頼
- **ラベル**: `documentation`, `question`

## 使い方

1. GitHubリポジトリの「Issues」タブを開く
2. 「New issue」ボタンをクリック
3. 作成したい内容に応じて適切なテンプレートを選択
4. テンプレートの各項目を記入
5. Issueを作成

## テンプレートの構成

各テンプレートは以下の要素で構成されています：

- **フロントマター**: GitHubが認識するメタデータ（名前、説明、ラベル）
- **セクション**: 絵文字付きの見出しで区切られた記入項目
- **プレースホルダー**: 括弧内に記入すべき内容の説明

## カスタマイズ

テンプレートをカスタマイズする場合は、以下の点に注意してください：

1. フロントマターは必ず`---`で囲む
2. `name`、`about`、`labels`は正しい形式で記述
3. マークダウンの書式を統一（見出しは`##`、リストは`-`を使用）
4. 各セクションの後には`---`で区切りを入れる

## 貢献

テンプレートの改善提案がある場合は、プルリクエストを送ってください。
